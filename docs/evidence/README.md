# OpsForge Evidence

This directory stores evidence supporting important engineering claims made
throughout OpsForge.

Evidence may include:

- command output
- benchmark results
- screenshots
- logs
- metrics
- failure observations
- recovery measurements
- architecture snapshots
- experiment notes

## Naming Convention

Use descriptive names that identify the phase and experiment.

Examples:

a5/pod-density-before-prefix-delegation.txt

a7/api-latency-dashboard.png

a8a/hpa-load-test-results.md

a8b/rollback-recovery-time.md

## Evidence Principle

Evidence is collected for meaningful engineering claims.

Not every command requires a screenshot.

The purpose is reproducibility and proof, not documentation volume.
